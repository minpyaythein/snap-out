何となく続けてしまうスクロールや動画視聴を、続ける前に計算問題を解かせることで中断させる Chrome 拡張機能です。

対象サイトは自分で選びます。設定した時間を超えると、画面にポップアップが現れます。計算を解けば、また自由に使えます。

---

## 特長

- **サイトごとの“ゆるい”制限** — 最大 6 サイトを登録でき、それぞれに時間の上限を設定（デフォルト 5 分、最大 30 分）
- **段階的な難易度** — 1 桁の四則演算から、対数・微分・積分・階乗まで 7 段階
- **通知のみモード** — 難易度を *なし* にすると、計算なしで閉じられるシンプルなバナーになります
- **複数タブ対応** — 同じサイトのすべてのタブで時間をまとめて計測。通知は全タブに表示され、どれか 1 つで解けば全部消えます
- **リロードでもすり抜け不可** — 新しいタブを開いても、ページを更新しても通知は回避できません
- **2 言語対応** — English / 日本語 の UI を、アプリ内ですぐに切り替え可能
- **リアルタイム計測** — ポップアップに現在のサイトでの累計時間をリアルタイム表示
- **プライバシー重視** — すべて Chrome のローカル／同期ストレージ内で完結。サーバーもアカウントも解析もなし

---

## なぜ作ったのか

気づいたら 1 時間もスクロールしていた、なんてことはありませんか？ snap-out は“流れを断ち切る”ための仕組みです。サイトをブロックしたり厳しい制限をかけたりするのではなく、続けるかどうかを *意識的に* 選ばせるだけです。

---

## 仕組み

1. 見すぎを防ぎたいサイトを最大 **6 件** 登録（例: `www.youtube.com`、`www.reddit.com`）
2. 通知が出るまでの時間を設定（デフォルト 5 分、最大 30 分）
3. 設定した時間を超えると、計算問題のオーバーレイが表示されます
4. 正解すると閉じられます。「おつかれさま！」という短い表示のあと、元の画面に戻ります。不正解だと画面が揺れて新しい問題が出ます
5. 閉じるとタイマーはリセットされます

もっと穏やかな通知がよければ、難易度を **なし** にしてください。計算問題の代わりに、そのまま閉じられるシンプルなバナーが出ます（解く必要はありません）。

**English と 日本語 に対応。** 言語はポップアップから選べます。UI と計算オーバーレイがすぐに切り替わります（計算自体は言語に依存しないため、変わるのは文言だけです）。

**タブをまたいで動作します。** サイトでの時間は、そのサイトのすべてのタブを合算して計測されます（YouTube を 2 タブ開いても 1 つのタイマーを共有）。通知が出るときは *すべての* タブに表示され、どれか 1 つのタブで解けば全部消えます。新しいタブを開いても、ページを更新しても回避はできません。

---

## 難易度レベル

| レベル | 種類 | 例 |
|---|---|---|
| なし | 計算なし — そのまま閉じられるバナー | _（「閉じる」を押すだけ）_ |
| やさしい | 2 つの値、+−×÷、1〜10 | `8 ÷ 2 = ?` |
| ふつう | 2 つの値、+−×÷、10〜99 | `63 × 47 = ?` |
| **むずかしい** *(デフォルト)* | 2 つの値、+−×÷、100〜999 | `847 ÷ 7 = ?` |
| とてもむずかしい | 3 つの値、+−×÷、100〜999 | `(4800 ÷ 20) − 153 = ?` |
| 超むずかしい | 複雑な式が 1 つ | `d/dx(x³) at x=4 = ?` |
| 不可能 | 複雑な式を 2 つ組み合わせ | `[log₂(32)] × [5!] = ?` |

「超むずかしい」と「不可能」には、対数・微分・積分・階乗が含まれます。

## インストール

> Chrome ウェブストアでの公開は準備中です。今のところは手動で読み込んでください。

1. このリポジトリをクローンまたはダウンロード
2. `chrome://extensions` を開く
3. 右上の **デベロッパーモード** を有効にする
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、プロジェクトのフォルダを選択
5. すぐ使えるように拡張機能をピン留め

---

## 使い方

1. ツールバーの snap-out アイコンをクリック
2. ホスト名を追加（例: `www.youtube.com`）
3. 通知までの時間（分・秒）を設定し、**適用** をクリック
4. ドロップダウンから難易度を選択（通知のみのバナーにするなら **なし**）
5. 言語（English / 日本語）を選択 — UI とオーバーレイがすぐに更新されます
6. いつもどおりブラウジング — snap-out がバックグラウンドで見守り、ポップアップには現在のサイトでの時間がリアルタイム表示されます
7. 時間になったら、問題を解いて閉じます

## ファイル構成

```
background.js     サービスワーカー — 時間を計測し、ポップアップを発火
content.js        計算問題のオーバーレイを挿入
content.css       オーバーレイのスタイル
storage.js        chrome.storage.sync のヘルパー
i18n.js           共有の EN/JA 辞書と参照（ポップアップ＋コンテンツスクリプト）
popup/            拡張機能のポップアップ UI（サイト一覧、通知時間、難易度選択、言語、リアルタイム計測）
```

---

## 権限

| 権限 | 用途 |
|---|---|
| `tabs` | どのサイトがアクティブかを検出 |
| `storage` | 登録サイトと難易度設定を保存 |
| `alarms` | 30 秒ごとに経過時間をチェック |
| `scripting` | 必要に応じてコンテンツスクリプトを挿入 |
| `host_permissions: <all_urls>` | 自分で選んだ任意のサイトで動作 |
